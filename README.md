# کنارت

**برای روزهایی که بیشتر به هم نیاز دارید.**

کنارت یک اپلیکیشن اندرویدی برای پیگیری چرخه قاعدگی است که برخلاف بیشتر Period Trackerها فقط برای یک نفر ساخته نشده: یک تجربه برای خودِ او و یک تجربه جدا برای پارتنرش دارد. هدف، آگاهی و ارتباط بهتر است — نه کلیشه‌سازی درباره رفتار زنان. تجربه چرخه برای هر فرد متفاوت است و همه متن‌های برنامه با همین نگاه («ممکن است»، «برای بعضی افراد») نوشته شده‌اند.

## امکانات

- **Onboarding**: صفحه شروع، انتخاب نقش («من هستم» / «پارتنر هستم»)، ثبت تاریخ آخرین پریود، طول چرخه (۲۱ تا ۴۵ روز) و مدت پریود (۲ تا ۱۰ روز)، گزینه «طول چرخه‌ام را نمی‌دانم».
- **داشبورد خانم**: روز چرخه روی یک حلقه رنگی، روزهای مانده تا پریود بعدی، مرحله تخمینی، بازه احتمالی تخمک‌گذاری، ثبت سریع شروع/پایان پریود و علائم، کارت «امروز به خودت بیشتر توجه کن».
- **داشبورد پارتنر**: وضعیت چرخه فقط در حد اجازه‌ای که داده شده، «امروز چطور می‌توانی کمک کنی؟»، «بهتر است انجام ندهی»، توصیه‌های روزانه.
- **تقویم ماهانه**: تقویم شمسی در فارسی و میلادی در انگلیسی؛ روزهای پریود، پیش‌بینی‌ها، مراحل چرخه، علائم ثبت‌شده و جزئیات هر روز.
- **ثبت علائم**: ۱۰ علامت با شدت (بدون علامت / خفیف / متوسط / شدید) و یادداشت شخصی؛ برای علائم شدید توصیه به مشورت با پزشک.
- **Insights**: میانگین و بازه طول چرخه‌های اخیر، نمودار ساده و تاریخچه قابل ویرایش (فقط آماری، بدون نتیجه‌گیری پزشکی).
- **اعلان‌ها**: متن جدا برای خانم و پارتنر، یادآوری پریود، تغییر مرحله، نکته‌های آموزشی، انتخاب ساعت (پیش‌فرض ۰۸:۳۰)، حالت «مخفی کردن اطلاعات حساس». با هر تغییر تاریخ یا طول چرخه، همه یادآوری‌ها لغو، دوباره محاسبه و زمان‌بندی می‌شوند؛ بعد از ری‌استارت گوشی هم دوباره تنظیم می‌شوند.
- **اتصال به پارتنر (Pairing)**: کد کوتاه مثل `KNT-7Q4M-2XA` که بدون سرور و بدون اینترنت کار می‌کند. خانم انتخاب می‌کند چه چیزی (مرحله، تاریخ احتمالی پریود، تعداد روز تا پریود) به اشتراک گذاشته شود؛ علائم، یادداشت‌ها و اطلاعات سلامت هرگز در کد نیستند.
- **محتوا**: ۳۰ توصیه برای خانم و ۳۰ توصیه برای پارتنر، دسته‌بندی‌شده بر اساس مرحله، مخاطب و نوع، در فایل‌های منبع (نه داخل UI).
- **زبان**: فارسی (پیش‌فرض، کاملاً RTL، اعداد فارسی، تاریخ شمسی) و English. فونت **Vazirmatn** به صورت محلی داخل برنامه است.
- **ظاهر**: Material 3، حالت روشن و تیره، پالت آرام و غیرکلیشه‌ای.

## حریم خصوصی

- بدون ثبت‌نام و ورود.
- همه اطلاعات فقط روی دستگاه (Room) ذخیره می‌شود. برنامه **اصلاً مجوز INTERNET ندارد**.
- اطلاعات از پشتیبان‌گیری ابری و انتقال به دستگاه دیگر مستثنا شده است.
- هیچ اطلاعات حساسی در Logcat چاپ نمی‌شود.
- اعلان‌ها روی صفحه قفل همیشه بدون جزئیات نمایش داده می‌شوند.
- «حذف همه اطلاعات» همه جدول‌ها، تنظیمات و یادآوری‌ها را پاک می‌کند.

## سلب مسئولیت پزشکی

اطلاعات و پیش‌بینی‌های این برنامه تقریبی هستند و ممکن است برای هر فرد متفاوت باشند. این برنامه ابزار تشخیص پزشکی یا روش پیشگیری از بارداری نیست. اگر علائم شدید، مداوم یا غیرمعمول دارید، با پزشک یا متخصص سلامت مشورت کنید.

# Kenaret (English)

*For the days you need each other most.*

Kenaret is a cycle tracker for couples. One experience is for the person who tracks her cycle, another for her partner. Reminders, advice and wording are different for each, always tentative ("may", "for some people") and free of hormone-blaming stereotypes.

## Features

- Onboarding (role choice, last period date, cycle length 21–45, period length 2–10, "I don't know my cycle length")
- Her dashboard: cycle ring, cycle day, days until next period, estimated phase, estimated ovulation **window**, quick logging, daily self-care
- Partner dashboard: only what she chose to share, "How can you help today?", "Better to avoid"
- Monthly calendar (Jalali in Persian, Gregorian in English) with periods, predictions, phases and symptoms
- Symptom tracking with severity and private notes
- Insights (statistics only) and editable period history
- Notifications with role-specific text, custom time, private mode; automatically cancelled → recalculated → rescheduled whenever data changes, and restored after reboot
- Offline pairing code with granular sharing permissions
- 30 + 30 non-repeating advice items (phase / audience / category)
- Persian (default, RTL) and English; bundled Vazirmatn font; light & dark themes
- Delete all data

## Technology

Kotlin · Jetpack Compose · Material 3 · Room · ViewModel · Navigation Compose · WorkManager · Kotlin Coroutines · JUnit

```
app/src/main/java/com/voria/kenaret/
├── cycle/          Cycle math, phases, statistics, Jalali calendar (pure Kotlin, unit-tested)
├── pairing/        Offline pairing code
├── notifications/  Reminder planner (pure), scheduler, workers, reboot receiver
├── database/       Room entities, DAO, database
├── data/           Repository (single source of truth)
├── content/        Advice catalog (generated from tools/advice_content.py)
├── domain/         Models
├── settings/       In-app language
└── ui/             Compose screens (onboarding, her, partner, calendar, symptoms, insights, learn, settings)
```

Advice text lives in `res/values/strings_advice.xml` (Persian) and `res/values-en/strings_advice.xml` (English). Edit `tools/advice_content.py` and run it to regenerate both files and the catalog.

## Build

Requirements: JDK 17 and the Android SDK (compileSdk 35).

```bash
./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # unit tests
```

## GitHub Actions

`.github/workflows/build-apk.yml` runs on every push to `main`, on pull requests and manually (**Run workflow**). It installs JDK 17 and the Android SDK, builds the debug APK, uploads it as the **`kenaret-debug-apk`** artifact, then runs the unit tests.

To download the APK: **Actions → Build APK → latest run → Artifacts → kenaret-debug-apk**.

The project is fully native Android: no Node.js / npm, so no JavaScript lock file is needed.

## Privacy

No account, no network permission, no analytics. All data stays on the device and is excluded from backups. Sensitive data is never logged. Lock-screen notifications never show details.

## Medical disclaimer

Information and predictions are approximate and may differ for each person. Kenaret is not a medical diagnostic tool or a method of contraception. If you have severe, persistent or unusual symptoms, please talk to a doctor or health professional. Kenaret never suggests medication or doses.
